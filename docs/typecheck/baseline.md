## Categories and recommended fixes

### 1. `sys.stdout.reconfigure(...)` on TextIO (3 errors) — `reportAttributeAccessIssue`

**Files**: [`__main__.py:8`](../../src/system_update/__main__.py:8), [`cli.py:41`](../../src/system_update/cli.py:41), [`config.py:619`](../../src/system_update/config.py:619)

**Why**: `sys.stdout` is typed as `TextIO`, but `reconfigure()` is only on the concrete `TextIOWrapper` subclass.

**Fix**: cast or `getattr` with fallback:

```python
# Option A — cast for the duration of the call
import io
if isinstance(sys.stdout, io.TextIOWrapper):
    sys.stdout.reconfigure(encoding='utf-8', errors='replace')

# Option B — keep the existing best-effort try/except shape, just narrow first
for stream in (sys.stdout, sys.stderr):
    if isinstance(stream, io.TextIOWrapper):
        try:
            stream.reconfigure(encoding='utf-8', errors='replace')
        except Exception:
            pass
```

### 2. `Optional[str]` → `str` arg (≈ 8 errors) — `reportArgumentType`

**Files**: `app.py:884`, `app.py:1179`, `export.py:83`, `export.py:589`, `cache.py:324`, `cache.py:326`, several test files.

**Why**: callers pass an `Optional[str]` (e.g. `output_file` flag value) to a parameter declared `str`.

**Fix**: either tighten the parameter type to `Optional[str]` and handle `None` inside, or assert/check at the call site:

```python
output_file = args.output or '-'   # default at the boundary
export(..., output_file=output_file)
```

### 3. `Optional` member access without narrowing (≈ 30 errors) — `reportOptionalMemberAccess` + `reportOptionalSubscript`

**Files**: `history.py` (13× — `self._conn.execute/commit/...`), `executors/__init__.py:149`, `tests/test_snapshots.py` (17×), `tests/test_smart_cache.py` (6×), `tests/test_config.py` (6×), `tests/test_scheduler.py`, `conftest.py`.

**Why**: attributes like `self._conn: Optional[sqlite3.Connection] = None` are accessed via `self._conn.execute(...)` without a `None` check.

**Fix in source code** (`history.py`): hoist the lazy-connect into a small helper that always returns a non-`None` connection:

```python
def _get_conn(self) -> sqlite3.Connection:
    if self._conn is None:
        self._conn = sqlite3.connect(self._path)
    return self._conn

# then everywhere: self._get_conn().execute(...)
```

**Fix in tests**: similar pattern — assert before subscripting:

```python
snap = store.get(...)
assert snap is not None
assert snap.label == ...
```

This category is the bulk of the noise. Worth a dedicated commit per file.

### 4. `dict` invariance in `checkers/__init__.py` (4 errors) — `reportArgumentType`

**File**: [`checkers/__init__.py:140-157`](../../src/system_update/checkers/__init__.py:140)

**Why**: a `Dict[str, Callable[[List[AppInfo]], int]]` is passed to a function declaring `Dict[str, Callable[[List[AppInfo]], object]]`. Pyright is correct — `dict` value type is invariant.

**Fix**: change the parameter from `Dict[...]` to `Mapping[...]` (covariant):

```python
from typing import Mapping
def _group_by_source(
    apps: List[AppInfo],
    source_checkers: Mapping[str, Callable[[List[AppInfo]], int]],
) -> ...:
```

### 5. `KeyboardInterrupt` is `BaseException`, not `Exception` (1 error)

**File**: [`tests/test_utils.py:444`](../../tests/test_utils.py:444)
