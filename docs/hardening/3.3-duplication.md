# Hardening 3.3 — Duplication

> **Section**: 3.3 of [HARDENING_PLAN.md](../../HARDENING_PLAN.md)
> **Priority**: 🟡 P2 / 🟢 P3
> **Status**: Specification — not implemented

## Why

Three duplication hotspots cause drift bugs:

1. The scanner registry is built twice — once in `app.py:_build_scanner_map`, once in `scanners/__init__.py`. Adding a scanner means editing both, and they drift (a scanner can be registered in one place but not invoked from the other).
2. `executors/commands.py` has parallel `_xxx` (update) and `_xxx_rb` (rollback) functions for every backend, with the same argv structure and the same error handling, copied N times.
3. `Path.home() / '.system_update'` is reimplemented in 6 modules, each with slightly different `mkdir(...)` flags.

These are all mechanical fixes. None change behavior; all reduce the surface area for future bugs.

## Items

### 3.3.1 — Single scanner registry via decorator

- **File**: [src/system_update/app.py:90](../../src/system_update/app.py:90), [src/system_update/scanners/__init__.py](../../src/system_update/scanners/__init__.py)
- **Effort**: M (½–1 day)
- **Plan**:
  1. In `scanners/__init__.py`, define a registry and a decorator:
     ```python
     _SCANNERS: dict[str, type[PackageScanner]] = {}

     def scanner(name: str):
         def deco(cls: type[PackageScanner]) -> type[PackageScanner]:
             _SCANNERS[name] = cls
             return cls
         return deco

     def get_scanner_map() -> dict[str, type[PackageScanner]]:
         return dict(_SCANNERS)
     ```
  2. Annotate each scanner class with `@scanner('winget')`, `@scanner('scoop')`, etc.
  3. Delete `_build_scanner_map` from `app.py`. The `SystemUpdateApp` calls `get_scanner_map()` instead.
  4. Apply the same pattern to `checkers/` if it has the same duplication (audit before assuming).
- **Tests** (`tests/test_scanners.py`):
  - Decorator registers a class.
  - `get_scanner_map()` is a defensive copy (mutating the result doesn't affect the registry).
  - Every built-in source name is present in the map.
- **Acceptance criteria**:
  - [ ] `_build_scanner_map` removed.
  - [ ] No source string appears in two registries.

### 3.3.2 — Unify update/rollback executors

- **File**: [src/system_update/executors/commands.py](../../src/system_update/executors/commands.py)
- **Effort**: M (½–1 day)
- **Plan**:
  1. Replace `_winget` / `_winget_rb`, `_npm` / `_npm_rb`, `_scoop` / `_scoop_rb`, etc. with one function per backend:
     ```python
     def _winget(action: Literal['install', 'uninstall', 'rollback'], app: AppInfo) -> CommandSpec:
         ...
     ```
     where `CommandSpec` is the existing argv builder return type.
  2. Map `action='install'` and `action='upgrade'` to the same winget invocation when appropriate; `action='rollback'` re-uses the same shape with `--version <previous>` from the snapshot.
  3. Pull common pre/post hooks (logging, dry-run check, env scrubbing) into a small wrapper at the dispatch site so each backend only describes "what to run".
- **Tests** (`tests/test_executors.py`):
  - Each backend produces the right argv for `install`, `upgrade`, `rollback`.
  - `--dry-run` yields no subprocess invocation.
  - Existing tests pass without modification.
- **Acceptance criteria**:
  - [ ] No `_xxx_rb` function remains.
  - [ ] Adding a new backend requires editing one place.

### 3.3.3 — Centralize `Path.home() / '.system_update'`

- **Files**: 6 modules currently re-implement this.
- **Effort**: S (≤2h)
- **Plan**:
  1. Implement (or reuse, if 1.4.2 lands first) `data_dir() -> Path` in `config.py` (or `paths.py`).
  2. Replace every `Path.home() / '.system_update'`, `os.path.expanduser('~/.system_update')`, and friends with `data_dir()`.
  3. Find sites:
     ```bash
     git grep -nE "(\.system_update|SYSTEM_UPDATE_HOME)" src/
     ```
  4. Honor `SYSTEM_UPDATE_HOME` env var (already documented in `AGENTS.md`).
- **Tests** (`tests/test_config.py`):
  - `data_dir()` honors the env var.
  - Multiple imports return the same path.
- **Acceptance criteria**:
  - [ ] `git grep -nE "Path\.home\(\)\s*/\s*'.system_update'" src/` returns no hits except in `data_dir()`.
